S'organiser sur Signal

Installer Signal, cacher son numéro, régler les messages éphémères, tenir des groupes de lutte, et savoir ce que Signal ne protège pas.

MessagerieGuide · 8 min

Pour s'organiser entre camarades, Signal est l'outil le plus simple et le plus sûr aujourd'hui. Les messages, les appels, les photos et les fichiers sont chiffrés de bout en bout : seules les personnes de la conversation peuvent les lire, ni Signal, ni ton opérateur, ni la police en interceptant le réseau. L'application est gratuite, son code est public, et elle est tenue par une fondation à but non lucratif, sans pub ni revente de données.

Mais Signal n'est qu'un outil. Bien réglé, il protège tes échanges ; mal réglé, il peut afficher ton numéro à n'importe qui ou garder des années de messages dans un téléphone saisi. Ce guide prend les réglages un par un.

1. Installer Signal

  • Téléphone : Google Play Store, App Store, ou, sur un Android sans Google, l'APK officiel depuis signal.org/android/apk. Méfie-toi des copies : l'éditeur doit être « Signal Foundation » ou « Signal Messenger ».
  • Ordinateur : Signal Desktop (Linux, Windows, Mac) depuis signal.org. Il se relie à ton téléphone par un QR code. Sous Linux Mint, suis les instructions du site (dépôt officiel).
  • Il faut un numéro de téléphone pour créer le compte. Il sert à t'envoyer le code d'activation ; on va ensuite le cacher.

2. Cacher ton numéro : le nom d'utilisateur

Par défaut, tes contacts te trouvent par ton numéro. Pour t'organiser avec des gens que tu ne connais pas encore (un collectif, une assemblée, une manif), donne plutôt un nom d'utilisateur : il ne révèle rien de toi et se change quand tu veux.

  1. CréerTouche ta photo de profil → Nom d'utilisateur. Choisis un pseudo, Signal ajoute deux chiffres (par exemple mamie.71).
  2. CacherParamètres → Confidentialité → Numéro de téléphone : « Qui peut voir mon numéro » sur Personne.
  3. Rester introuvableAu même endroit, « Qui peut me trouver par mon numéro » sur Personne si tu ne veux pas que quelqu'un qui a ton numéro sache que tu es sur Signal.
  4. PartagerSur la page du nom d'utilisateur, un lien et un QR code à donner au lieu de ton numéro. Tu peux les réinitialiser s'ils ont trop circulé.

Ton nom de profil se voit dans tous les groupes où tu es. Mets un prénom d'usage ou un pseudo, et une photo qui ne te reconnaît pas.

3. Protéger ton compte

  • Code PIN Signal : Paramètres → Compte → Code PIN Signal. Choisis-en un long. Il protège ton profil et tes contacts si tu changes de téléphone.
  • Verrouillage de l'inscription : Paramètres → Compte → Verrouillage de l'inscription, activé. Sans ton PIN, personne ne peut réinscrire ton numéro sur un autre téléphone, même en récupérant ta carte SIM.
  • Appareils liés : Paramètres → Appareils liés. Regarde la liste de temps en temps, et supprime tout appareil que tu ne reconnais pas : il lit tous tes nouveaux messages.

Arnaque au QR code. Un QR code « pour rejoindre un groupe » envoyé par quelqu'un que tu ne connais pas peut en réalité relier son ordinateur à ton compte. Ne scanne un QR code de liaison que pour ton propre ordinateur, depuis Appareils liés.

4. Les messages éphémères

Ce qui n'existe plus ne peut pas être lu, ni par une personne qui récupère un téléphone, ni dans une procédure. Les messages éphémères s'effacent tout seuls chez tout le monde après le délai choisi.

  • Pour toutes les nouvelles conversations : Paramètres → Confidentialité → Minuterie par défaut des nouvelles conversations. Une semaine est un bon réglage de départ ; un jour pour l'organisation d'une action.
  • Pour une conversation ou un groupe : touche le nom en haut → Messages éphémères. Dans un groupe, c'est valable pour tout le monde.

Rien n'empêche quelqu'un de faire une capture d'écran ou de recopier un message. Les messages éphémères limitent les traces, ils ne remplacent pas la confiance.

5. Protéger le téléphone lui-même

Signal chiffre le trajet des messages. Une fois arrivés, ils sont lisibles par quiconque déverrouille ton téléphone. C'est souvent là que tout se joue.

RéglageOùPourquoi
Code de déverrouillage longRéglages du téléphone6 chiffres minimum, mieux : une phrase de passe. Un schéma se devine aux traces de doigts.
Pas d'empreinte ni de visage en actionRéglages du téléphoneOn peut te forcer à poser ton doigt ou à regarder l'écran. Désactive-les avant une manif, ou éteins le téléphone.
Verrouillage de SignalConfidentialité → Verrouillage de l'écranSignal redemande ton code après quelques minutes.
Sécurité de l'écranConfidentialité (Android) ou « Masquer l'écran dans le sélecteur d'apps » (iPhone)Pas d'aperçu des conversations dans les applis récentes, pas de capture sur Android.
Notifications discrètesParamètres → Notifications → Afficher : « Aucun nom ni contenu »Rien ne s'affiche sur l'écran verrouillé.
Appels relayésConfidentialité → Avancé → Toujours relayer les appelsTon adresse IP n'est pas visible par la personne que tu appelles.

En garde à vue, la police peut te demander le code de ton téléphone. En France, refuser de donner le code d'un téléphone chiffré peut être poursuivi. Avant une action, renseigne-toi auprès de la legal team ou d'une avocate ou d'un avocat, et pose-toi la question : ai-je besoin d'emporter ce téléphone ?

6. Tenir un groupe de lutte

  • Un groupe par besoin : un pour l'info large, un petit pour l'organisation, un tout petit pour ce qui est sensible. Plus un groupe est grand, plus il est probable qu'il y ait une personne indiscrète, ou infiltrée.
  • Lien d'invitation avec validation : touche le nom du groupe → Lien du groupe, active Approuver les nouveaux membres. Réinitialise le lien s'il a circulé trop loin.
  • Droits : dans les réglages du groupe, réserve aux admins la modification des infos et l'ajout de membres. Plusieurs admins de confiance, pas une seule personne.
  • Messages éphémères activés pour tout le groupe, dès la création.
  • Faire le ménage : retire les personnes qui ne participent plus, et ferme les groupes devenus inutiles.
  • Le bon outil pour la bonne info : une adresse de rendez-vous ou un nom ne s'écrivent pas dans un groupe de 300 personnes. Ce qui est vraiment sensible se dit de vive voix, téléphones loin.

7. Vérifier qu'on parle à la bonne personne

Chaque conversation a un numéro de sécurité. Si vous le comparez en vrai, tu as la certitude que personne ne s'est glissé entre vous.

  1. Ouvre la conversation, touche le nom en haut → Afficher le numéro de sécurité.
  2. Quand vous êtes ensemble, scannez tour à tour le QR code de l'autre : la personne est marquée vérifiée.
  3. Si Signal annonce que le numéro de sécurité a changé, c'est souvent un nouveau téléphone. Demande-le à la personne par un autre moyen avant d'écrire quoi que ce soit de sensible.

8. Ce que Signal ne protège pas

  • Un téléphone déverrouillé ou infecté par un logiciel espion : tout ce qui s'affiche à l'écran peut être lu.
  • Les personnes : une capture d'écran, un message transféré, une personne infiltrée dans le groupe.
  • Le fait d'être sur Signal et le fait d'avoir ton téléphone sur toi : ton opérateur sait où est ton téléphone, même si Signal ne dit rien de tes messages.
  • Les sauvegardes : une photo enregistrée dans la galerie peut partir dans un cloud (Google Photos, iCloud). Dans les réglages de Signal, évite d'enregistrer automatiquement les médias.

À retenir. Nom d'utilisateur à la place du numéro, PIN et verrouillage de l'inscription, messages éphémères par défaut, téléphone bien verrouillé, petits groupes. Et ce qui est vraiment sensible ne s'écrit pas.
