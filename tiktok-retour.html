Connecter TikTok

Pour que les nouveaux TikTok de Mamie arrivent tout seuls sur le site. À faire une fois par an.

1. Demander l'autorisation

Colle la Client key de l'application TikTok (pas la « Client secret » !), puis clique. TikTok te demandera de te connecter avec le compte @mamie_commune et d'accepter.

2. Copier le code dans GitHub

Vite : le code ne vaut que quelques minutes.

Voici le code renvoyé par TikTok :

  1. Ouvre le dépôt GitHub du site, onglet Actions.
  2. Choisis « Connecter TikTok », puis Run workflow.
  3. Colle le code dans la case, et lance.

Quand le robot est vert, c'est fini : les nouveaux TikTok arriveront tout seuls dans les 3 heures.
