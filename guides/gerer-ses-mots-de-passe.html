Gérer ses mots de passe

Une phrase de passe solide, un mot de passe différent par compte, un coffre comme KeePassXC et la double authentification.

Guide numériqueSécurité3 min de lectureAjouté le 2 novembre 2026

Mamie a gardé longtemps le même code pour sa porte, sa carte bleue et son cadenas de vélo. Le jour où quelqu'un l'a trouvé, il avait tout. Sur internet, c'est la même histoire en plus rapide : quand un site se fait voler sa base de données, les mots de passe sont essayés partout ailleurs.

Les trois règles

  1. Un mot de passe différent pour chaque compte. C'est la règle la plus importante.
  2. Des mots de passe longs. La longueur compte plus que les signes bizarres.
  3. Un endroit sûr pour les ranger : un gestionnaire de mots de passe, pas un carnet dans le sac ni un fichier « mdp.txt ».

La phrase de passe

Pour les quelques mots de passe que tu dois retenir (le code de l'ordinateur, le mot de passe maître du coffre), prends une phrase de passe : cinq ou six mots tirés au hasard, par exemple avec des dés et une liste de mots, ou avec le générateur de KeePassXC. Elle est longue, donc solide, et facile à retenir avec une petite histoire.

  • Ne prends pas une phrase connue (citation, paroles de chanson) : elles sont dans les listes des pirates.
  • Pas de date de naissance, de nom d'animal ou de ville : ça se trouve sur les réseaux.

Le coffre : KeePassXC

KeePassXC range tous tes mots de passe dans un fichier chiffré, sur ton ordinateur. Tu ne retiens que le mot de passe maître.

  1. Installe KeePassXC depuis son site officiel ou la logithèque de Linux.
  2. Crée une nouvelle base de données et choisis une phrase de passe comme mot de passe maître.
  3. Pour chaque compte, ajoute une entrée et utilise le générateur pour créer un mot de passe long.
  4. Change en priorité les mots de passe de ta boîte e-mail (elle sert à réinitialiser tout le reste), puis des comptes importants.
  5. Sauvegarde le fichier (une copie sur une clé USB rangée ailleurs) : voir Faire des sauvegardes.

Si tu oublies le mot de passe maître, personne ne pourra ouvrir le coffre, pas même la bande. Écris-le une fois sur papier et range-le dans un endroit vraiment sûr, le temps de le retenir.

La double authentification

La double authentification (ou « 2FA ») demande, en plus du mot de passe, un code à usage unique. Même si ton mot de passe fuit, le compte reste fermé.

  • Préfère un code donné par une application (Aegis sur Android, par exemple) plutôt qu'un code par SMS : un numéro de téléphone peut être détourné.
  • Garde les codes de secours fournis par le site, dans ton coffre KeePassXC.

Les mots de passe du collectif

  • Un compte partagé (le compte Instagram du collectif, la boîte e-mail commune) : une base KeePassXC à part, partagée seulement avec les personnes mandatées.
  • Quand quelqu'un quitte le groupe, on change les mots de passe qu'il ou elle connaissait. Ce n'est pas de la méfiance, c'est de l'hygiène.
  • Jamais de mot de passe envoyé dans un groupe de discussion : de vive voix, ou dans un message Signal éphémère.
