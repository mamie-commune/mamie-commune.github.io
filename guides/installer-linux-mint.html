Installer Linux Mint pas à pas

De la clé USB au premier démarrage : télécharger, préparer la clé, tester en live, installer.

Linux MintGuide · 3 min

Avant de commencer

  • Sauvegarde tes documents sur un disque externe. L'installation peut effacer le disque interne. Voir le guide Faire des sauvegardes.
  • Prévois une clé USB d'au moins 8 Go (son contenu sera effacé) et une demi-journée.
  • Branche l'ordinateur sur secteur et, si possible, sur un câble réseau.
  • Choisis ton édition : Cinnamon à partir de 4 Go de RAM, Xfce pour les machines plus modestes. Voir Choisir une distribution.

1. Télécharger l'image ISO

Sur le site officiel de Linux Mint, rubrique « Download », prends la dernière version (22.x) dans l'édition choisie. Le fichier fait environ 3 Go et se termine par .iso. Télécharge-le uniquement depuis le site officiel ou l'un de ses miroirs.

Les plus prudent·es vérifient la somme de contrôle SHA256 indiquée sur la page de téléchargement. Sous Linux : sha256sum linuxmint-22.iso.

2. Préparer la clé USB

Copier l'ISO sur la clé ne suffit pas : il faut l'« écrire » avec un outil dédié.

  • Depuis Windows : Rufus ou balenaEtcher. Choisis la clé, l'image ISO, puis « Démarrer ». Garde les options par défaut.
  • Depuis Linux : l'outil « Créateur de clé USB » (mintstick) ou balenaEtcher.
  • Ventoy permet de mettre plusieurs ISO sur une même clé et de choisir au démarrage.

3. Démarrer sur la clé et tester

  1. Clé branchée, redémarre l'ordinateur.
  2. Pendant l'allumage, appuie sur la touche du menu de démarrage. Selon la marque : F12 (Dell, Lenovo), F9 (HP), F11 ou F8 (Asus, MSI), Échap ou F2 sur d'autres.
  3. Choisis la clé USB (parfois listée comme « UEFI: nom de la clé »).
  4. Dans le menu de Mint, valide « Start Linux Mint ». Le bureau « live » s'ouvre : rien n'est modifié sur ton disque.

Profite de ce mode pour vérifier le wifi, le son, la webcam, l'écran et l'imprimante. Si tout marche ici, tout marchera une fois installé.

Si la clé n'apparaît pas, désactive « Secure Boot » ou « Fast Boot » dans le BIOS/UEFI (touche F2 ou Suppr au démarrage). Sous Windows, désactive aussi le « démarrage rapide » dans les options d'alimentation.

4. Installer

  1. Double-clique sur « Install Linux Mint » sur le bureau live.
  2. Langue : Français. Clavier : Français (variante par défaut).
  3. Coche l'installation des codecs multimédias.
  4. Type d'installation :
    • Installer à côté de Windows : double démarrage, tu choisis le système à chaque allumage.
    • Effacer le disque et installer Linux Mint : remplace tout. Uniquement si ta sauvegarde est faite.
  5. Fuseau horaire, puis nom, nom de l'ordinateur et mot de passe. Note ce mot de passe : il sert aussi pour les mises à jour.
  6. Attends la fin (15 à 30 minutes), redémarre, retire la clé quand on te le demande.

5. Juste après

  • L'écran d'accueil s'ouvre : fais les mises à jour, choisis des miroirs rapides, installe les pilotes si un matériel ne marche pas.
  • Crée un premier instantané Timeshift une fois tout réglé.
  • Continue avec Personnaliser Linux Mint.
