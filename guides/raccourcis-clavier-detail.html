Raccourcis clavier en détail

Fenêtres, bureaux, système, lanceurs, dépannage et clavier : la liste complète pour Mint Cinnamon et Ubuntu.

Linux MintGuide · 3 min

Bureaux et vues

  • Vue d'ensemble des fenêtres : Ctrl+Alt+↓ (Mint), Super+W (Ubuntu, conseillé partout).
  • Vue des espaces de travail : Ctrl+Alt+↑ ou Alt+F1 (Mint), Super+S (Ubuntu, conseillé).
  • Passer d'une fenêtre à l'autre de la même application : Alt+² (absent de Windows).
  • Lancer une commande : Alt+F2 (Mint).
  • Lecteur d'écran : Alt+Super+S. Désactive-le si tu le déclenches par erreur.

Fenêtres

  • Basculer maximisé : Alt+F10 (Mint) ; conseillé Super+Page↑.
  • Restaurer : Alt+F5.
  • Menu de la fenêtre : Alt+Espace.
  • Déplacer au clavier : Alt+F7, flèches, puis Échap.
  • Redimensionner au clavier : Alt+F8, flèches, puis Échap.
  • Demi-écran : Super+flèche (conseillé partout ; Ubuntu utilise Ctrl+Super+flèche).
  • Quart d'écran : Ctrl+Alt+pavé numérique (Ubuntu), non assigné sous Mint.

Système

  • Verrouiller : Ctrl+Alt+L (Mint) ; conseillé aussi Super+L.
  • Redémarrer Cinnamon (bureau figé) : Ctrl+Alt+Échap.
  • Menu d'extinction : Ctrl+Alt+Fin.
  • Changer la configuration des écrans : Super+P.
  • Enregistrer une vidéo de l'écran : Maj+Ctrl+Alt+R (Mint).

Lanceurs

  • Terminal : Ctrl+Alt+T.
  • Dossier personnel : Super+E.
  • Moniteur système : à créer, conseillé Ctrl+Alt+M (Windows : Ctrl+Maj+Échap).

Souris et panneau

  • Clic sur une tâche : afficher ou réduire. Clic milieu : fermer, ou ouvrir une nouvelle fenêtre depuis un lanceur.
  • Copier rapide : sélectionner du texte suffit. Coller rapide : clic milieu.

En cas de blocage total

Maintiens Alt+Impr (touche « Syst ») et tape :

  • K : redémarrer l'interface graphique ;
  • B : redémarrage forcé ;
  • O : extinction forcée.

Fichiers

  • Mettre à la corbeille : Suppr. Supprimer définitivement : Maj+Suppr.

Le clavier

  • AltGr+touche : caractère alternatif. Maj+AltGr+touche : un quatrième caractère (absent de Windows).
  • Verr Maj donne la ponctuation et les majuscules accentuées (É, À, Ç), pas les chiffres comme sous Windows.

Nos conseils

  • Désactive les raccourcis d'accessibilité si tu ne t'en sers pas.
  • Reprends ceux de Windows quand c'est possible (Super+E, Super+flèches, Super+L).
  • Profite des trois raccourcis possibles par action sous Mint.
