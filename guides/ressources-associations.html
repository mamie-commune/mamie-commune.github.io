Accueil/Outils numériques/Logiciels

Outils libres pour les associations

Gestion, compta, dons, travail collaboratif, communication et hébergement pour les assos, collectifs et petites structures.

LogicielsGuide · 2 min

Objectif : garder la main sur tes données et ne dépendre d'aucun éditeur. L'idéal est l'auto-hébergement, si quelqu'un dans le collectif peut l'administrer.

Se faire accompagner

  • Le guide de l'April pour les associations, le projet Emancip'Asso et ses webinaires, les fiches des CHATONS.
  • Les prestataires d'Emancip'Asso, les CEMÉA, La Mouette (bureautique libre).
  • À éviter : les programmes Solidatech et TechSoup, liés aux géants américains.

Dons et paiements

  • Liberapay et Open Collective (frais Stripe ≈ 1,5 % + 0,25 € par paiement).
  • Paiement via la banque de l'asso, avec reçus fiscaux.
  • HelloAsso : commissions « suggérées » aux donateur·ices et données chez Microsoft ; si tu l'utilises, explique qu'on peut mettre la contribution à zéro.

Travailler ensemble

  • Rendez-vous : Framadate. Décisions : Loomio. Tâches : un kanban type Kanboard.
  • Textes et tableurs à plusieurs, sans compte : Etherpad, Ethercalc, CryptPad (chiffré).
  • Fichiers : Nextcloud, avec Collabora ou OnlyOffice pour éditer en ligne.
  • Discussion d'équipe : Mattermost, Rocket.Chat, Matrix, ou un groupe Signal.
  • Listes de diffusion : Sympa.
  • Visio : Jitsi Meet, BigBlueButton.

Communiquer dehors

  • Mail avec ton nom de domaine, chez un hébergeur éthique.
  • Site web chez un hébergeur associatif ; vidéos sur PeerTube.
  • Événements : Mobilizon. Boutique : WooCommerce ou PrestaShop.
