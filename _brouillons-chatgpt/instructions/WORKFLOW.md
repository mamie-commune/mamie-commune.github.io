# Workflow éditorial ChatGPT ↔ Claude Code

## Rôle de ChatGPT
Préparer les dossiers, structurer les contenus, proposer des bibliographies et signaler les limites de vérification.

## Rôle de Claude Code
Examiner le dépôt réel, comparer les brouillons aux contenus existants, vérifier les références, préparer les adaptations techniques et tester localement lorsque l'intégration est autorisée.

## Rôle du responsable du site
Valider les modifications éditoriales et techniques, décider de la fusion vers `main` et autoriser toute publication.

## Séparation brouillon / production
Les textes de `_brouillons-chatgpt/` ne sont pas des contenus publics. Leur présence dans GitHub ne vaut ni validation éditoriale, ni autorisation de publication.

## Publication
La branche `contenus-chatgpt` ne doit pas déclencher le workflow de production. La publication ne doit intervenir qu'après fusion volontaire dans la branche principale, conformément à la configuration réelle du dépôt.
