Linux Mint en bref

Linux Mint est un système pour ordinateurs personnels, dérivé d'Ubuntu. Sa prise en main est très facile à facile.

Les éditions

Xfce

  • Pour les machines peu puissantes : 3 Go de RAM conseillés, peu de besoins graphiques.
  • Utilisé par d'autres distributions, simple à configurer.

Cinnamon

  • Un peu plus gourmand : 4 Go de RAM conseillés.
  • Développé par l'équipe de Mint. Plus de réglages, plus soigné visuellement.

MATE

Entre les deux, en ressources comme en fonctionnalités.

Les cinq versions se ressemblent beaucoup à l'usage. Si tu es encore en 20 ou avant, passe à une version supportée : voir Mises à jour.

Nouveautés utiles

  • Warpinator (depuis Mint 20) : envoie des fichiers à un autre ordinateur du même réseau. Lance-le sur les deux machines, elles se trouvent toutes seules, choisis les fichiers. Une application Android non officielle existe sur F-Droid pour échanger avec un téléphone en wifi. Voir aussi Partage de données.
  • Relevés du système (depuis Mint 21) : une icône signale ce qui manque (codecs, langues, pilotes).

Aide-mémoire

  • Installer un logiciel : Menu → Logithèque → chercher → Installer.
  • Mettre à jour : Menu → Gestionnaire de mises à jour → Installer les mises à jour.
  • Sauvegarder le système : Menu → Timeshift.
  • Réglages : Menu → Paramètres système (Cinnamon) ou Gestionnaire de paramètres (Xfce).
  • Pilotes : Menu → Gestionnaire de pilotes.
  • Envoyer des fichiers en local : Menu → Warpinator.
